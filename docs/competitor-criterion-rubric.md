# Competitor Criterion Rubric

## Scoring Scale (0.0 to 100.0)

For each AI-assisted criterion, the AI utilizes a standardized scoring rubric based on comparative evaluation.

### marketPositionScore
- **0-20**: Target has negligible market presence compared to Reference.
- **21-40**: Target is a minor player in shared markets.
- **41-60**: Target holds comparable market share/presence.
- **61-80**: Target is a recognized market leader with significant advantages.
- **81-100**: Target completely dominates the shared markets.

### competitiveCapabilityScore
- **0-20**: Target capabilities (products/services) are vastly inferior.
- **21-40**: Target has notable gaps in capabilities.
- **41-60**: Target capabilities are broadly equivalent.
- **61-80**: Target offers superior or more innovative capabilities.
- **81-100**: Target capabilities disrupt the market and set industry standards.

### strategicIntentScore
- **0-20**: Target shows no strategic focus overlapping with Reference.
- **21-40**: Target exhibits passive or defensive strategy.
- **41-60**: Target and Reference share similar strategic directions.
- **61-80**: Target pursues highly aggressive, proactive strategies.
- **81-100**: Target strategy directly targets and undermines the Reference.

### growthMomentumScore
- **0-20**: Target is experiencing significant decline.
- **21-40**: Target growth is stagnating.
- **41-60**: Target growth parallels the market average.
- **61-80**: Target exhibits rapid, above-average growth.
- **81-100**: Target is in a phase of explosive, sustained hyper-growth.

### competitiveThreatScore
- **0-20**: Target poses minimal threat; focuses on distinct niches.
- **21-40**: Target poses moderate, indirect threat.
- **41-60**: Target is a direct, standard competitor.
- **61-80**: Target poses a significant, immediate threat to core business.
- **81-100**: Target represents an existential threat to the Reference's market viability.

### productMarketOverlapScore (Deterministic)
Calculated algorithmically via Jaccard index or similar deterministic models. AI does not intervene.
